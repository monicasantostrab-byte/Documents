# 💧 Controle de Níveis de àgua

# 📚 Sobre o projeto

Esse programa simula o monitoramento de um reservatório de água, com 5 níveis de mediçãodo reservatório.
E, apresenta mensagens de alerta com diferentes cores de acordo com o nível encontrado.

# 🎯 Objetivo

💧 Simula cinco níveis de água do reservatório.
📋 Armazena as situações em uma lista.
🎨 Define uma cor específica para cada nível.
🚨 Exibe mensagens de alerta conforme a situação do reservatório.
🔄 Utiliza a estrutura de repetição for para percorrer os níveis.
♻️ Restaura a formatação padrão do terminal após cada mensagem.
