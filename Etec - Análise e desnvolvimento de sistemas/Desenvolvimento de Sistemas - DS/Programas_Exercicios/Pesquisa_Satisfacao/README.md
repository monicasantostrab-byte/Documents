# 📊 Pesquisa de Satisfação TudoWeb

## 📌 Sobre o projeto

Este é um programa em Python para realizar a pesquisa de opinião com 50 clientes da empresa Tudo Web, o objetivo de avaliar o grau de satisfação em relação ao as campanhas desenvolvidas pelo nosso time.

## 🎯 Objetivo

O programa coleta informações dos entrevistados e registra suas opiniões, permitindo visualizar a quantidade de avaliações positivas e negativas ao final da pesquisa.


## ⚙️ Funcionalidades

# 👤 Solicita o nome do entrevistado.
# 🎂 Solicita a idade do participante.
# 📝 Registra a opinião sobre o atendimento.
# 🔄 Utiliza a estrutura de repetição for para realizar 50 entrevistas.
# ⭐ Contabiliza as avaliações excelentes.
# ❌ Contabiliza as avaliações ruins.
# 📊 Apresenta o resultado final da pesquisa.


## 💻 Tecnologias utilizadas

Python
Visual Studio Code (VS Code)
